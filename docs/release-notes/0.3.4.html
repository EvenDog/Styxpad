Updates inside Styxpad

  • Download and install new versions without dragging an app into Applications each time.
  • Choose Check for Updates from the menu bar or Settings to install and restart.
  • Automatic checks and downloads are available in Settings. Downloaded updates install when you quit; your profiles are kept.
  • Updates and the update feed are cryptographically signed, and release installers are notarized by Apple.

Coming from 0.3.3 or earlier? Install 0.3.4 once using the DMG. Future versions can update inside the app.
